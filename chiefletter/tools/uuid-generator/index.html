UUID generator

Generate random version 4 UUIDs.

Generate five random version 4 UUIDs with the browser cryptographic random number generator. A UUID is a 128-bit identifier formatted as hexadecimal groups. It is useful for identifiers where a central counter would be inconvenient.

Use it here

UUID generator

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Choose Generate UUIDs.
  2. Copy one identifier into a test record or development fixture.
  3. Keep the identifier in the expected text format, including hyphens, unless your system specifies another representation.

Use cases

  • Create sample IDs for local test data.
  • Make a client-side identifier for a draft record before saving it.
  • Prepare unique-looking fixture values for documentation examples.

Notes and limits

A UUID is not an access token. Do not treat an identifier as proof of permission or secrecy. Enforce authorization on the resource it names.

Frequently asked questions

Can UUIDs collide?

A collision is extremely unlikely for random version 4 values, but uniqueness is not a mathematical guarantee. Enforce database constraints where required.

What does version 4 mean?

Version 4 UUIDs use random bits with fixed version and variant fields.

Are generated UUIDs stored?

No. The generator creates them in your browser and does not keep a history.
