HTML structure inspector

Inspect element hierarchy, tag counts, and basic document structure.

Parse a pasted HTML fragment in an inert browser document and report element counts, heading order, missing image alt attributes, and a compact element outline. The inspector does not execute scripts from the input.

Use it here

HTML structure inspector

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Paste a fragment or a complete HTML document.
  2. Choose Inspect structure.
  3. Review the outline and warnings, then check important findings in the target page and browser accessibility tree.

Use cases

  • Understand the nesting in an unfamiliar snippet.
  • Find images without alt attributes in sample markup.
  • Check whether headings skip levels in a content fragment.

Notes and limits

This is a quick structural check, not a full accessibility audit. It does not inspect CSS contrast, keyboard behavior, dynamic states, or the meaning of alternative text.

Frequently asked questions

Does pasted script run?

No. The input is parsed as a document and scripts are not executed.

Does a heading outline prove the page is accessible?

No. Headings help, but names, focus order, semantics, contrast, and interaction behavior also matter.

Why does the browser repair my markup?

HTML parsers recover from many markup errors. The resulting outline shows the parsed structure, not every source mistake.
