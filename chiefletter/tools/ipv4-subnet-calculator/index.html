IPv4 subnet calculator

Calculate network, broadcast, mask, and host range from an IPv4 CIDR.

Calculate common IPv4 subnet values from an address and CIDR prefix. The result includes the network and broadcast addresses, subnet mask, wildcard mask, and address range. This is a planning aid. Confirm routing, reservations, and provider-specific rules before changing a live network.

IPv4 subnet calculator

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Enter an IPv4 address and prefix, such as 192.168.10.23/24.
  2. Choose Calculate subnet.
  3. Review the network range and confirm it does not overlap with another network in your environment.

Use cases

  • Check whether two IPv4 addresses fall in the same subnet.
  • Plan a private network range for a lab.
  • Read the usable range and broadcast address before writing network notes.

Notes and limits

The calculator uses standard IPv4 CIDR math. It does not know your organization’s existing routes, reserved addresses, DHCP pools, cloud provider limits, or firewall rules. Prefixes /31 and /32 have special point-to-point and single-address uses, so interpret host counts in context.

Frequently asked questions

What does /24 mean?

It means the first 24 bits identify the network. The remaining 8 bits identify addresses within that block.

Does the calculator detect overlapping networks?

It calculates one block at a time. Compare the network ranges yourself or calculate each network separately.

Why is the usable host count different for /31?

A /31 block is commonly used for point-to-point links under RFC 3021, where both addresses can be used as endpoints. Traditional subnet conventions treat network and broadcast addresses differently.

Does this work for IPv6?

No. This tool calculates IPv4 addresses only.
