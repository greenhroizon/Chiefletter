CSS box shadow generator

Adjust a shadow visually and copy the resulting CSS declaration.

Build a CSS box-shadow declaration by adjusting horizontal and vertical offsets, blur, spread, color, and opacity. The preview updates while you edit. Copy the generated value and check it against real content, focus states, and contrast needs.

CSS box shadow generator

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Adjust the offset, blur, spread, and color controls.
  2. Review the preview at normal and narrow widths.
  3. Copy the CSS declaration and add it to your stylesheet or design token.

Use cases

  • Create a subtle card shadow for a prototype.
  • Compare elevation values before setting design tokens.
  • Understand how blur, spread, and offset change a shadow.

Notes and limits

A shadow is not a substitute for a visible focus indicator or sufficient contrast. Effects can look different across displays and backgrounds. Use restrained values and test the component in its real layout.

Frequently asked questions

What does spread do?

Spread expands or contracts the shadow before blur is applied.

Can I use this for inset shadows?

This version generates an outer shadow. Add the inset keyword in your stylesheet if your design needs an inner shadow.

Does the tool change a website?

No. It previews the CSS and provides a declaration to copy.
