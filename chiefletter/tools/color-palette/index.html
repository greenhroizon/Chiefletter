Color palette generator

Generate five colors and copy their hex values.

Generate five related colors from a random hue and a small range of lightness values. The palette is a starting point for interface or illustration work. Select any swatch to copy its hexadecimal value.

Use it here

Color palette generator

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Choose Generate palette to create a set of five colors.
  2. Click a swatch to copy its hex value. The button confirms when copying succeeds.
  3. Generate more options, then test the chosen colors in the actual interface and check text contrast.

Use cases

  • Find a quick set of colors for a prototype.
  • Explore a few starting hues before building a design system.
  • Collect hex values for a small graphic or presentation.

Notes and limits

A palette is not an accessibility check. Test foreground and background pairs with a contrast checker and review every state, including hover, error, and disabled controls.

Frequently asked questions

Are these palettes guaranteed to be accessible?

No. The generator makes related colors, not verified contrast pairs. Check every text and control combination separately.

How do I copy a color?

Select the swatch. Its hexadecimal value is copied to the clipboard.

Can I save a palette?

Copy each color value into your design file or notes. The generator does not keep a gallery or account history.
