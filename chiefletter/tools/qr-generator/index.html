QR code generator

Make a QR code without sending its contents away.

Turn a short string or URL into a downloadable QR image. The code is built on a canvas in your browser, with no QR API request. This compact implementation supports byte-mode text up to 106 UTF-8 bytes. Long content, including full documents, does not fit.

Use it here

QR code generator

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Enter a short URL or text. Keep it below the stated byte limit.
  2. Choose Make QR code and wait for the black-and-white code to appear.
  3. Download the PNG, then scan it with a phone before printing or sharing it.

Use cases

  • Share a short public web address on a poster or handout.
  • Open a Wi-Fi or event information page from a printed card.
  • Move a brief, non-sensitive string from a screen to a phone.

Notes and limits

Do not encode passwords, private keys, personal records, or confidential links. Anyone who scans the printed code can read its content. Test the final printed size and contrast.

Frequently asked questions

What is the text limit?

The local generator supports up to 106 UTF-8 bytes. Non-English characters use multiple bytes, so they reach the limit sooner.

Does the QR image expire?

The image itself does not expire. A URL inside it might stop working if the destination changes.

Why should I scan the image before printing?

A phone scan confirms the code has enough contrast, quiet space, and physical size for the intended use.
