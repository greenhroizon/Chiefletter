HTML entity encoder and decoder

Escape HTML characters or read encoded text.

Escape characters that have special meaning in HTML or decode common entity references into text. The encoder replaces ampersands, angle brackets, quotation marks, and apostrophes. The decoder uses a text area element and does not insert decoded content into the page as HTML.

Use it here

HTML entity encoder and decoder

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Choose Escape HTML or Decode HTML entities.
  2. Paste a short text sample and run the conversion.
  3. When writing a website, still use the framework’s context-aware escaping instead of relying on a one-off conversion.

Use cases

  • Show a code sample containing angle brackets in a document.
  • Read a copied value containing named or numeric entities.
  • Check what a small HTML fragment looks like after basic escaping.

Notes and limits

Escaping depends on where data appears. Text nodes, attributes, URLs, and JavaScript contexts require different handling. This utility is not a substitute for safe template rendering.

Frequently asked questions

Does encoding make HTML safe everywhere?

No. It escapes a small set of characters for text use. Other contexts need context-aware validation and escaping.

Which entities can the decoder read?

The browser decodes standard named and numeric HTML entities.

Does decoded markup execute?

No. The result is read from a textarea value and displayed as text.
