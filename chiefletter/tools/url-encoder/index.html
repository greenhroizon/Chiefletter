URL encoder

Encode text for safe use in a URL.

Use this when text needs to travel inside one part of a URL. The encoder converts spaces, punctuation, and non-ASCII characters to percent-encoded bytes. It uses encodeURIComponent, so it leaves URL separators such as a slash untouched only when those characters are part of the component you submit.

Use it here

URL encoder

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Paste the value you plan to place in a query parameter or path segment.
  2. Choose Run tool. Copy the encoded result into the matching URL component.
  3. Encode each value once. Keep the surrounding URL, parameter names, equals signs, and ampersands outside the input.

Use cases

  • Add a search phrase with spaces or punctuation to a query parameter.
  • Prepare a callback value or return path for a URL parameter.
  • Check how accented letters and non-Latin text appear after URL encoding.

Notes and limits

Encode components, not a complete URL. If you encode a whole address, separators such as : and / turn into data and the address stops working as a URL.

Frequently asked questions

Does this encode a complete URL?

It encodes the text as one URL component. Do not paste a complete URL unless you intend to encode every separator too.

Why do spaces become %20?

Percent encoding represents a byte with a percent sign and two hexadecimal digits. Space is byte 20 in hexadecimal.

Is encoded text encrypted?

No. Encoding changes representation. Anyone who sees the URL can decode its value.
