Typing speed test

Measure typing speed, accuracy, and errors over a timed passage.

Measure words per minute, character accuracy, and errors while typing a short passage. The clock begins with the first keystroke. Choose a 30- or 60-second round. Scores update in the browser, and the test text is not uploaded.

Use it here

Typing speed test

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Choose a time limit.
  2. Type the passage shown above the entry field. The timer starts as soon as you begin.
  3. Read the score when the passage is complete or time runs out. Reset the test to take another round.

Use cases

  • Get a baseline before practising touch typing.
  • Compare two short practice sessions on the same device.
  • Find whether accuracy or speed needs more attention.

Notes and limits

This passage is short and the result is only an estimate. Keyboard layout, language, punctuation, device, and pasting affect the score. Use repeated rounds for a steadier baseline.

Frequently asked questions

How is WPM calculated?

Correct characters are divided by five, then converted to a per-minute rate using elapsed time.

Does pasting count as typing?

The test records text entered in the field. For a meaningful personal score, type the passage instead of pasting it.

Are errors penalized?

The page reports incorrect characters and calculates accuracy from the typed character count.
