Image compressor

Compress JPG, PNG, and WebP images in your browser, then download smaller copies.

Reduce image file size with the browser canvas API. Choose an output format and quality, compress multiple images, compare the before and after sizes, and download each result. Processing stays on this page. Once compression finishes, the selected source files are cleared from the tool and the result files remain available for download.

Use it here

Image compressor

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Select one or more JPG, PNG, or WebP images. Use output format and quality controls to set the result.
  2. Choose Compress images and review the new file size and savings for each image.
  3. Download each compressed result. The tool clears source selections after compression; the original files on your device are unchanged.

Use cases

  • Prepare smaller images for a website or email.
  • Compare WebP and JPEG output sizes for a photo.
  • Reduce large screenshots before adding them to a document.

Notes and limits

Compression quality and format affect visual detail and file size. Canvas output does not preserve every metadata field, such as camera data or color profiles. Transparent areas stay transparent in WebP or PNG, but JPEG has no transparency. Check image quality before publishing. The browser cannot delete files from your device, and this tool never attempts to.

Frequently asked questions

Are my photos uploaded?

No. The browser reads and converts each selected image locally. The page does not send the image to Chiefletter.

Does compression delete the original file?

No. A website cannot silently delete a file from your device. The tool clears its selected source files from the page after processing. Your original files remain where you saved them.

Which format should I choose?

WebP often gives a smaller web image, JPEG works for photographs without transparency, and PNG keeps lossless detail or transparency. Compare the result for your use.

Why did a PNG become larger?

Lossless or highly detailed PNG files may not shrink through the browser’s export path. Try WebP, or keep the original if the output grows or loses needed detail.

Does the tool keep camera metadata?

Canvas export generally removes much of the source metadata. Keep the original if you need EXIF or other embedded information.
