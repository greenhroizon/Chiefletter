URL decoder

Decode percent-encoded text.

Read percent-encoded URL components without changing the original address. The decoder converts percent sequences back to text and treats plus signs as spaces, which matches common query-string encoding. Invalid or incomplete escape sequences return an error so you can find malformed input.

Use it here

URL decoder

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Copy the encoded value from a URL, log, or request.
  2. Paste the component and run the decoder.
  3. Compare the result with the original request before editing a live link. Decode only as many times as the value was encoded.

Use cases

  • Read a search query from a copied URL.
  • Inspect a return path or callback parameter while debugging.
  • Check whether an unexpected plus sign represents a space or a literal plus.

Notes and limits

A literal plus in query data is often encoded as %2B. This tool treats an unescaped plus as a space. Use the matching encoder when you create new values.

Frequently asked questions

Why does + become a space?

Many query-string formats use plus for spaces. A literal plus should normally appear as %2B.

What does URIError mean?

The input contains a malformed percent escape or invalid encoded UTF-8. Copy the exact component again and check its percent pairs.

Should I decode a URL more than once?

Only when you know the value was encoded more than once. Repeated decoding might change data that was meant to remain literal.
