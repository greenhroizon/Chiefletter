Image resizer

Resize images to exact pixel dimensions while keeping their proportions.

Create a resized image in your browser by setting a target width and height in pixels. Preserve the source proportions by default, choose an output format and quality, then download the result. Files stay local to the page, and the source image on your device remains unchanged.

Use it here

Image resizer

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Choose an image and enter the target width and height in pixels.
  2. Keep Preserve proportions enabled for a proportional resize, or turn it off for an exact crop-free stretch.
  3. Choose Resize image, inspect the preview, and download the result.

Use cases

  • Create a smaller copy for a website card or profile image.
  • Prepare a fixed-size image for a presentation.
  • Check how a photo looks at a target width before exporting it from a design tool.

Notes and limits

Resizing down discards detail that cannot be recovered by later enlarging. A resize does not crop the image. Use a dedicated crop tool when the frame must have a specific composition. Canvas export can remove source metadata and can change color handling.

Frequently asked questions

Does resizing overwrite my original?

No. The tool creates a new file and leaves the original untouched.

What does Preserve proportions do?

It keeps the original width-to-height ratio and fits the image inside the requested dimensions.

Can I use this to crop a photo?

No. It changes dimensions by scaling the full image. Use an image editor with crop controls when you need to remove edges.

Will the resized image keep metadata?

Canvas export usually removes much of the original metadata. Keep a separate original if you need those fields.
