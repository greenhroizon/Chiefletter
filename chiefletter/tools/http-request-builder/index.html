HTTP request builder

Create a safely quoted curl command from a method, URL, headers, and body.

Create a shell-quoted curl command from an HTTP method, URL, optional headers, and a text body. The builder does not send the request, so you can inspect the command before running it.

Use it here

HTTP request builder

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Enter an HTTP or HTTPS URL and choose a method.
  2. Add headers one per line using `Name: value`. Add a body when the method needs one.
  3. Copy the command, inspect it, and run only in an environment where the request is safe.

Use cases

  • Prepare a repeatable local API request.
  • Share a sanitized curl example in a bug report.
  • Check header and body quoting before using a terminal.

Notes and limits

The generated command may include credentials you typed. Do not share or paste a live secret into a public channel. A GET request may still change state on a poorly designed service, so understand the destination first.

Frequently asked questions

Does this send the request?

No. It generates command text only.

How should headers be entered?

Use one header per line in the form `Name: value`.

Does shell quoting work on every terminal?

The output targets POSIX-style shells. Windows PowerShell and command prompt use different quoting rules.
