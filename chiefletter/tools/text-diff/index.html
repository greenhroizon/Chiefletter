Text comparison

Compare two text blocks line by line.

Compare two text blocks line by line. Matching lines receive a neutral prefix. Lines at the same position that differ appear as a removal and an addition. This simple comparison is useful for quick reviews, but it does not calculate a minimal edit sequence.

Use it here

Text comparison

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Paste the earlier version into Original text.
  2. Paste the new version into Changed text.
  3. Compare the marked lines and inspect the surrounding context before accepting a change.

Use cases

  • Review a small paragraph after editing.
  • Compare two configuration snippets before copying one.
  • Spot a changed list item in a short draft.

Notes and limits

Insertions near the start shift later lines, so this view might mark several following lines as different. Use a proper version-control diff for source code or large files.

Frequently asked questions

Does this show the smallest set of changes?

No. It compares matching positions, not the shortest edit sequence. A moved line may appear as a removal and an addition.

Are spaces significant?

Yes. The comparison uses the exact text of each line.

Can it compare files?

Paste text from two small files. The tool does not read local files from disk.
