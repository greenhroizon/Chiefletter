Turn tab-separated or pipe-separated rows into a Markdown table. The first row becomes the header. Pipes inside cells are escaped so the table structure stays intact.

Markdown table generator

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Paste rows with tabs or pipe separators. Use one line per row.
  2. Run Generate table.
  3. Copy the Markdown and check the destination platform’s table support.

Use cases

  • Create a compact comparison table in a README.
  • Format a small set of configuration values for documentation.
  • Turn spreadsheet rows into a Markdown draft.

Notes and limits

This is a simple delimited-text converter, not a full spreadsheet importer. Use tabs for cells that contain commas. Markdown table support varies between renderers.

Frequently asked questions

How are columns separated?

Tabs take priority when a line contains tabs. Otherwise, pipe characters divide cells.

Can cells contain a pipe?

The output escapes pipe characters. Review how your target Markdown renderer handles escaped pipes.

Are formulas or formatting preserved?

No. The tool converts plain text values only.
