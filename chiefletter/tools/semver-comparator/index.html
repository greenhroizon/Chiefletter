Semantic version comparator

Compare semantic versions, including prerelease identifiers.

Compare versions that follow the core Semantic Versioning format major.minor.patch, with optional prerelease and build metadata. Numeric components compare numerically. Prereleases sort before the matching stable release.

Use it here

Semantic version comparator

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Enter two versions, with or without a leading v.
  2. Run Compare versions.
  3. Review the result and confirm the package follows Semantic Versioning rather than a custom scheme.

Use cases

  • Check whether a release is newer than a pinned dependency.
  • Compare prerelease builds before publishing.
  • Explain major, minor, and patch ordering in a release note.

Notes and limits

This checker does not evaluate version ranges such as ^2.1.0 or package-manager tags such as latest. Build metadata does not affect precedence.

Frequently asked questions

Is 1.10.0 newer than 1.9.0?

Yes. Each numeric component compares as a number, so minor 10 is greater than minor 9.

Where does 2.0.0-rc.1 sort?

A prerelease sorts before 2.0.0.

Do build labels affect ordering?

No. SemVer build metadata after a plus sign does not change precedence.
