Password generator

Create a random password in your browser.

Generate a random password with the browser’s cryptographic random number generator. Choose a length from 8 to 128 characters and select a character set. The generator includes at least one character from each selected group, then shuffles the result.

Use it here

Password generator

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Set a length that fits the service. Longer passwords provide more possible combinations.
  2. Choose the character groups accepted by the account form.
  3. Generate, then copy the password into a password manager. Avoid saving it in a document or message.

Use cases

  • Create a unique password for a new account.
  • Generate a temporary development credential for a local test system.
  • Replace a reused password after moving the account to a password manager.

Notes and limits

Use a different password for every service. The generator does not store or recover the result. Save it in a trusted password manager before leaving the page.

Frequently asked questions

How random is the password?

The generator uses crypto.getRandomValues and removes modulo bias when selecting characters. Browser and device security still matter.

Does Chiefletter receive the password?

No. Generation and copying happen in your browser. The page does not send the generated value to Chiefletter.

What length should I choose?

Use the longest length the service accepts. A password manager makes longer, unique passwords practical to store.
