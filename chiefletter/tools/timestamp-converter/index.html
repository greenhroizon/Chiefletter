Timestamp converter

Convert a date or Unix timestamp in your browser.

Convert Unix timestamps, ISO-style date text, or a local date and time. The result shows UTC, Unix seconds, Unix milliseconds, and the browser’s local display. Ten-digit numeric values are treated as seconds; longer numeric values are treated as milliseconds.

Timestamp converter

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Enter a Unix timestamp or a date string. Use the date control for local time.
  2. Choose Convert timestamp. Use the current-time control when you need a quick reference.
  3. Compare the UTC and local outputs before copying a value into logs or code.

Use cases

  • Read an event timestamp from an application log.
  • Convert an API expiration time while debugging.
  • Check the difference between a stored UTC value and local display.

Notes and limits

A date without a timezone may be interpreted as local time by the browser. Include Z or an explicit offset when you mean a specific UTC instant.

Frequently asked questions

Are timestamps in seconds or milliseconds?

The tool treats ten-digit numbers as seconds and longer numeric values as milliseconds. Check the source format if the value has another length.

Why does local time differ from UTC?

Local time applies the browser device’s timezone and daylight-saving rules. UTC does not.

Does this tool account for leap seconds?

No. JavaScript Date follows the time model used by the browser and does not represent leap seconds.
