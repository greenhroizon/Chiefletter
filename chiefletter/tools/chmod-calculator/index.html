Unix permission calculator

Convert owner, group, and other permission bits to chmod notation.

Convert three Unix permission digits into a symbolic rwx string and a chmod command. Each digit combines read as 4, write as 2, and execute as 1.

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Set owner, group, and other digits from 0 to 7.
  2. Read the symbolic permissions and octal mode.
  3. Use the command only after checking the target path and the access your service needs.

Use cases

  • Understand a mode shown by ls -l.
  • Prepare a chmod mode for a local project file.
  • Compare owner and group access before changing a script.

Notes and limits

Permissions control access on Unix-like systems, but ownership, ACLs, mount options, and service configuration also matter. Avoid recursive permission changes on broad system paths.

Frequently asked questions

What does chmod 755 mean?

Owner receives read, write, and execute. Group and other receive read and execute.

Why is execute permission needed on a directory?

On a directory, execute permission allows traversal and access to entries, subject to other permissions.

Does the tool change a file?

No. It only calculates a mode and displays a command.
