JSON formatter and validator

Validate JSON syntax and format it for reading.

Validate JSON syntax and make a compact document easier to inspect. The formatter uses the browser’s JSON parser, then writes valid data with two-space indentation. It reports syntax errors instead of guessing how to repair the document.

Use it here

JSON formatter and validator

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Paste a JSON object, array, string, number, boolean, or null value.
  2. Run the formatter. Review the formatted output and copy it into your editor.
  3. If validation fails, read the parser message and check the nearby comma, quote, bracket, or value.

Use cases

  • Inspect an API response copied from a local development session.
  • Tidy a configuration file before a code review.
  • Confirm a JSON snippet parses before adding it to a project.

Notes and limits

JSON requires double-quoted property names and strings. It does not support comments, trailing commas, undefined, or single-quoted strings.

Frequently asked questions

Does the formatter repair invalid JSON?

No. It validates and formats valid JSON. Fix the reported syntax problem, then run it again.

Are comments allowed in JSON?

Standard JSON has no comment syntax. Some configuration formats extend JSON, but this tool checks standard JSON only.

Is my input uploaded?

No. Parsing and formatting run in this browser page. Do not paste secrets into a shared or public computer.
