Base64 encoder and decoder

Convert Unicode text to or from Base64.

Convert Unicode text to Base64 or decode Base64 back into readable text. The tool converts through UTF-8, so common international characters work. Base64 is a transport format, not a privacy or security feature.

Use it here

Base64 encoder and decoder

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Choose whether to encode text or decode Base64.
  2. Paste the value and run the tool.
  3. Copy the result into the software or document expecting that format. Keep binary file data out of this text-only utility.

Use cases

  • Inspect a short Base64 value from a development log.
  • Prepare text for a system field that expects Base64.
  • Check whether a value contains readable UTF-8 text.

Notes and limits

Do not use Base64 to hide passwords, tokens, or private information. It is easy to reverse and provides no encryption.

Frequently asked questions

Is Base64 encryption?

No. It is a reversible encoding. Anyone with the value can decode it.

Why does decoding fail?

The input might not be valid Base64 or might decode to bytes that are not valid UTF-8 text.

Does it work with emoji?

Yes, ordinary Unicode text is converted through UTF-8 before encoding.
