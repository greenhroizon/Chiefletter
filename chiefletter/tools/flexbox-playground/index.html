Flexbox playground

Adjust flex direction, alignment, spacing, and item count in a live preview.

Change common CSS Flexbox properties and view the result with numbered sample items. The preview updates as you change direction, justification, alignment, gap, or item count.

Use it here

Flexbox playground

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Choose a flex direction and alignment values.
  2. Adjust the gap and number of items.
  3. Copy the generated CSS, then test it with your actual content and viewport sizes.

Use cases

  • Learn how justify-content differs from align-items.
  • Check a row layout before editing a component.
  • Compare wrapping and spacing choices in a small preview.

Notes and limits

The playground uses short sample labels and a fixed preview area. Real text, intrinsic item sizes, writing direction, and responsive rules may change the result.

Frequently asked questions

What is the difference between justify-content and align-items?

Justify-content distributes items along the main axis. Align-items positions them along the cross axis.

Does the playground generate HTML?

No. It shows sample items and provides the CSS properties to copy.

Why does a real layout look different?

Content size, container size, wrapping, writing direction, and other CSS rules affect the final layout.
