URL slug generator

Turn a title into a clean, readable URL slug.

Turn a title into a lowercase slug for a readable URL path. The generator normalizes accented characters, removes punctuation, replaces runs of separators with a hyphen, and trims hyphens from the ends.

Use it here

URL slug generator

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Paste a short title or label.
  2. Run the tool to produce a lowercase slug.
  3. Review the result for meaning, length, and collisions before publishing a URL.

Use cases

  • Create a path for a new article or documentation page.
  • Make filenames from task titles.
  • Normalize a list of labels before using them as route names.

Notes and limits

A slug does not check whether a URL is already in use. When you rename a published page, preserve the old route or add a redirect so existing links keep working.

Frequently asked questions

Why are some characters removed?

The tool keeps basic Latin letters and numbers, then uses hyphens between words. Other symbols are removed after Unicode normalization.

Should a slug include the full title?

Use enough words to identify the page. Short, specific slugs are easier to read and maintain.

Does this page change my website URL?

No. It only creates text for you to copy into your publishing system.
