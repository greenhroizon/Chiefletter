Cron expression explainer

Validate and explain the five fields in a standard cron expression.

Validate and explain the five standard cron fields: minute, hour, day of month, month, and day of week. The parser supports numbers, wildcards, lists, ranges, and step values.

Use it here

Cron expression explainer

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Enter five fields separated by spaces, such as `*/15 9-17 * * 1-5`.
  2. Run Explain expression.
  3. Check the hosting system’s cron dialect and time zone before scheduling a real job.

Use cases

  • Read a scheduled job from a deployment file.
  • Check field order before changing a cron entry.
  • Explain a weekday or interval schedule to a teammate.

Notes and limits

Cron dialects differ. This tool does not resolve named months, named weekdays, macros, or every scheduler’s day-of-month/day-of-week rules. Server time zones and daylight-saving behavior depend on the scheduler.

Frequently asked questions

What does */15 mean?

In a supported field, it selects every fifteenth value within that field’s range.

Does the tool show exact future run times?

No. It validates and explains fields but does not predict scheduler behavior or time-zone transitions.

Does every cron service use five fields?

No. Some add seconds, year, or special macros. Check the scheduler documentation.
