HTML metadata inspector

Check a page’s title, description, canonical URL, social metadata, and heading structure.

Inspect an HTML page or fragment locally for common head metadata and content structure. The report checks title and description presence, viewport metadata, canonical URL, Open Graph fields, heading counts, and image alt attributes. It parses source text without running page scripts. This is a practical pre-publish check, not a ranking score or complete accessibility audit.

HTML metadata inspector

Runs in your browser. Your input is not sent to Chiefletter.

How to use this tool

  1. Paste the page HTML or load the example. Include the head and body when you want a full report.
  2. Choose Inspect HTML and review each check. Verify missing fields and values in your source page.
  3. Recheck the actual published page because server templates and build tools may change the final HTML.

Use cases

  • Review a page before publishing it.
  • Check whether social preview fields exist in a template.
  • Find missing image alt attributes or multiple top-level headings in a small page.

Notes and limits

The inspector analyzes only the text you provide. It does not fetch a URL, evaluate JavaScript, verify whether canonical URLs resolve, test image content, or judge whether the description fits the page. A present metadata field can still be inaccurate. Review the result in context and test accessibility with other methods.

Frequently asked questions

Does the inspector visit my website?

No. It only parses HTML you paste into the page. It does not send or fetch the content.

Does a passing report guarantee good SEO?

No. It checks a set of common page signals. Search visibility depends on content, site quality, indexing, and many other factors.

Does it run scripts from the pasted HTML?

No. The tool parses the text as an inert HTML document and reads selected fields.

Why does the report differ from my published page?

Your server, CMS, or build step may add or change metadata. Inspect the final page source as well as your template.
