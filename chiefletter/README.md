# ChiefLetter — static site

Deploy this folder as the site root (Vercel preset: Other; no build command). The site uses clean URLs configured in `vercel.json`.

## Owner setup before launch

- Verify ownership of `chiefletter.com` and that `contact@chiefletter.com` is active and monitored.
- Confirm the AdSense publisher ID and configure consent/privacy controls for the regions and audiences served. The loader is present; no ad units or ad placements are included.
- Add the publisher’s legal identity, responsible editor, governing-law jurisdiction and any required privacy contact details.
- If claiming a registered DMCA agent, provide the legal name and complete any required registration; the current DMCA page is an instruction for notices, not proof of registration.
- Review all copy, legal text and publication dates before launch. This package does not guarantee ad-network approval.

See `sitemap.xml` and `robots.txt`; article illustrations are locally hosted SVG files under `images/`.
