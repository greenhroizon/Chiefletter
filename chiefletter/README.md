# ChiefLetter - Vercel deploy

1. Put these files at the ROOT of your repo (index.html must be top-level) or run `npx vercel` inside this folder.
2. Vercel: Framework Preset = Other, Build Command empty, Output Directory empty.
3. Add your domain, replace https://www.chiefletter.com and contact@chiefletter.com if different.
4. Submit /sitemap.xml in Google Search Console.
